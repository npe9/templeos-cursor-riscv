## What the levels mean

| level | meaning |
|---|---|
| **L0-FAIL** | does not compile against the RV kernel — a symbol or feature the port does not have |
| **L1-TRAP** | compiles and links, then FAULTS when loaded into a real kernel image |
| **L1-HANG** | loads but never reaches the end of boot |
| **L1-OK** | loads into a real image, boots, initialises graphics and survives |

L1 is the level above "it compiles". It only became measurable once the 141 unguarded
trailing autoruns were wrapped in `#ifndef RV_NO_DEMO_AUTORUN` — before that, including one
of these files RAN it at load, and the fault was blamed on whatever harness included it.

Note what L1 does NOT claim: that the program does anything useful. Four programs are driven
with scripted input and checked for a real response — Halogen, MassSpring, BattleLines and
Lines (`make kernel-game-{input,mouse,scanchar,lines}-smoke`). Everything else is untested
above L1.
