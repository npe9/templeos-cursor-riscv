# Bare-metal HolyC REPL

Interactive HolyC on RISC-V (UART console). Language surface matches a source file: functions,
classes, globals, `#define`, statements. Statements compile and run immediately; the
result prints in hex unless you use `Print` / `"fmt", args;`.

Default seed MMIO (`MEM_*` in `MemMapSelected.hc`, regenerated by `make -C templeos-riscv
syncconfig`) matches the active Kconfig board — CI default is **virt**. Flip boards with
`defconfig-*`, then rebuild `repl.elf` if you need the REPL to follow —
[PLATFORM.md](../templeos-riscv/PLATFORM.md) / [KCONFIG.md](../templeos-riscv/KCONFIG.md).

## Run

**Product paths (HolyC-only guest)** — see [SELF_HOST.md](SELF_HOST.md):

```bash
make                         # host holyc-riscv (bootstrap AOT; stays C)
# A2 guest Cmp compile REPL (Kernel+Compiler_RV ExePutS):
make repl-cmp && qemu-system-riscv64 -M virt -m 128M -bios none -kernel build/repl-cmp.elf -nographic
make repl-cmp-smoke
# Memfs/Dir honesty bridge (ExePutS→thin Jit; do not grow jit.hc):
make repl-holyc
qemu-system-riscv64 -M virt -bios none -kernel build/repl-holyc.elf -nographic
make repl-holyc-smoke
make repl-holyc-regression
make bootloader-smoke        # split HolyC boot + payload
```

**Deprecated legacy C guest** (`worry_dream_repl.c`) — still **required** CI dual-run until A3 flip
([SELF_HOST.md](SELF_HOST.md) blockers). Local: `SKIP_REPL_LEGACY=1 make qemu-integration`.

```bash
make                         # host holyc-riscv (needed by some seeds / fmt bridges)
make repl-blob               # rebuild boot runtime snapshot (after editing seed/*.hc)
cd bootstrap
make clean && make -f Makefile.repl
qemu-system-riscv64 -M virt -bios none -kernel repl.elf -nographic
# Default QEMU virt RAM is 128MiB — enough (memfs @ 0x87800000). make -f Makefile.repl run
```

Boot loads a **prebuilt HolyC snapshot** (`boot_blob_embed.h`, built by `make repl-blob` /
`bootstrap/gen_boot_blob.py`) via one `run_source` of the concatenated seeds — not
`Run("mem.hc")` per file. Individual seeds land in a hierarchical memfs (`Lib/print.hc`,
`Tutorials/A01_RV64I.hc`, …). Bare names (`Run("print.hc")`, `Cat("boot.hc")`) still
resolve while basenames stay unique. The generator AOT-validates the concat with
`holyc-riscv` when available (`bootstrap/boot_runtime.bin`).

### Memfs layout

```
/Home          user files (hello on the AOT guest)
/Tmp           scratch
/Boot          boot.hc, start.hc, trap/timer, MemMapSelected, …
/Lib           print, str, fs, uart, mem, dir, files, run, …
/Apps          Vi/Edit/Ed, Funs, Callers
/Asm           asm_doc, asm_complete, disasm
/Doc           man, man_topics, tutorial
/Doc/Datasheet ds_uart.hc, ds_csr.hc, …
/Tutorials     A01_*.hc, B*.hc, C*.hc
```

`Dir;` lists the current directory (subdirs as `name/`). `Cd("Tutorials");` `Pwd;`
`MkDir("Home/Work");` (alias of TempleOS `DirMk`). Kernel/Drv is not in this REPL tree.

Compile errors print as `file:line:col: error: …` (host `holyc-riscv` and the UART REPL).
`ErrGo;` opens the preferred editor on the last error site.

From repo root:

```bash
make repl-cmp-smoke          # A2: guest Compiler_RV ExePutS UART loop
make repl-holyc-smoke        # HolyC memfs/Dir bridge smoke
make repl-holyc-regression   # HolyC honesty subset (expand toward full flip)
make bootloader-smoke        # HolyC split-boot product path
make repl-smoke              # deprecated legacy C guest
make repl-regression         # deprecated legacy honesty gate
```

See [tests/REGRESSION.md](../tests/REGRESSION.md) for what “PASS” must mean. Local emulator
invocation for the harness is documented in [CI.md](CI.md) only.

## Boot welcome and history

On start, `boot.hc` prints `[boot] HolyC primitives loaded…` then `Help;` — a short
capability overview (eval, editors, Man, MemMap/Regs, asm, timer, files, keys, soft
`Reset;`). Type `Help;` again anytime. To leave a session, use guest `Reset;` (re-enter boot)
or your platform’s normal halt/reset; do not treat host-emulator key sequences as product UI.

Readline history is **preloaded** (oldest→newest) so **Up** walks demos first:

`Help;` → `1+2*3;` → `Man("Clint");` → `Man("Print");` → `Src("Dir");` → `MemMap;` →
`Regs;` → `Dir;` → `Cat("boot.hc");` → asm/`Reg("a7")` → `Uf("Print");` → `Fmt("boot.hc");`

(Seed lives in C `hist_seed()` in `worry_dream_repl.c`; banner text in `bootstrap/seed/boot.hc`.)

**Up/Down** recall whole **compile units**, not individual physical lines: a multi-line
function entered across several Enters is one history entry (embedded newlines). While a unit
is still open (unbalanced `{`/`(`), the prompt stays on **`... `** continuation instead of
printing a fresh **`> `** until braces/parens balance and the unit compiles.

## Everyday commands

| Action | Example |
|--------|---------|
| Define + call | `I64 Add(I64 a,I64 b){return a+b;}` then `Add(40,2);` → `0x2a` |
| Print | `"x=%d\n", 42;` |
| Edit source | `Src("Dir");` / `Src("hello.hc");` — preferred editor (Vi default); `:q` / `q` returns to REPL, then `Run` |
| Goto def | Vi: `gd` / `^]` / Enter on symbol; EditHoly: `^]` / `^G`. Pushes a buffer session (memfs spill, depth 4) and loads `SrcFile("Name")` in the same editor loop; `:q` / `^X` pops. Resolve: srcmap file → srcmap text spill → memfs / `Name.hc` → `DocFileFor` (Man topics). No full TempleOS hash `SrcLink` yet. |
| Man under cursor | Vi: `K` or `gM` → `Man(ident)` then press a key to redraw. EditHoly: `^K`. |
| Format file | `Fmt("file.hc");` — host `HolyFmtSrc` (same as `holyc-riscv --fmt`) |
| Help / symbols | `Help;` `Man("Print");` `Man("CLINT");` / `Man("Clint");` `SrcFile("Print");` — on thin `repl-holyc`: same Man/topics + `FunsList;` / `SrcFileRep;` (interactive FunPick = legacy) |
| Function picker | `Funs;` — grouped by topic (`Sections;`); type to filter, Tab=next topic, Enter=`Src`, `^G`=`Man`, Esc quit. Filter dump (no Esc): `Funs("Uart");`. Full dump: `FunsList;` |
| Debug | `MemMap;` `Regs;` `StkRep;` `Bp(&Fn);` `U(pc-16);` — full matrix in [DEBUGGER.md](DEBUGGER.md). Host-slot Regs/StkRep on legacy `repl.elf`; watch/step WIP. MemMap last column = HolyC driver (`MemMapDrvFind("uart")`) |
| Datasheet | `DsFind("uart");` `DsShow("mstatus");` `DsDecode("mstatus");` `Bits("uart.lsr", 0x21);` — bitfield decode from OS-owned sheets ([DATASHEET.md](DATASHEET.md), `Man("Datasheet")`) |
| Tab complete | Partial token before cursor: functions / globals, **`#define`s** (`MEM_PLIC`, `MEM_UART`, … from live `define_table` / `csr.hc`), or memfs paths. Case-insensitive. `asm{}` → opcodes / GPRs / CSRs (`asm_complete.hc`). Editors use the same `CompTab` path. |
| Export files | `DumpChanges;` / `ZmodemSend("boot.hc");` / `TrzszSend("boot.hc");` / `FsChanges;` / `ZmodemSendChanges;` / `TrzszSendChanges;` — UART framed dump, ZMODEM, or native trzsz ([FILE_EXPORT.md](FILE_EXPORT.md)). |

`Man("Name")` covers HolyC functions (doc blocks above definitions) and **topics/symbols** in
`bootstrap/seed/man_topics.hc` — hardware like **CLINT** / **PLIC**, `MEM_*` addresses, CSR
timer bits (`MTIE` / `MIE`). Lookup is case-insensitive where practical (`Clint` / `CLINT`).
Example: `Man("CLINT")` prints this board profile’s `mtime`/`mtimecmp` via `MEM_*` and the
`SetTrap` → `TrapInit` → `TimerArm` → `wfi` programming path.

Default editor is Kconfig **Editors** (`Vi` / `Edit` / `Ed`) → `bootstrap/seed/RVEditorSelected.hc`.
Override live: `editor=&EditHoly;` / `editor=&EdHoly;` / `editor=&Vi;`.

Host formatter from the Mac/Linux side:

```bash
./holyc-riscv --fmt [--stdout] file.hc…
make fmt-test
```

## Inline `asm{}` (RISC-V)

Unlabeled `asm{}` on the host/REPL path emits raw RV via `TryAssembleRiscV`. Notes:

- No `subi` — use `addi rd, rs, -imm`.
- `sub` is R-type only (`sub rd, rs1, rs2`).
- ABI names `a0`–`a7`, `s0`–`s11`, … work.
- CSR ops accept numeric immediates or names from `csr.hc` (`mstatus`, `mepc`, …).
- Tab inside `asm{}` completes opcodes / registers / CSR names (REPL C readline + editor `CompTab`; tables in `bootstrap/seed/asm_complete.hc`).
- Tab outside `asm{}` also completes live `#define`s (`MEM_*`, `UART_*`, …) from the compiler `define_table` — same macros `csr.hc` / seeds publish (no hard-coded address list).
- Guest destination assembler is `Compiler/Asm_RV.HC` (`CMP_RV_ASM`).

```holyc
asm {
  li a7, 20
  addi a7, a7, -4
};
Regs;
```

More: [COMPILER_RV.md](../templeos-riscv/COMPILER_RV.md) (asm section).

## Ctrl-C interrupt

| Context | Behavior |
|---------|----------|
| At `>` prompt | Clears the draft line, prints `^C` / `Interrupted`, stays at the prompt |
| During eval (busy `for(;;)`, …) | UART RX IRQ (PLIC #10 on the default virt-style map) sets a break flag; trapvec aborts the eval — `Interrupted` back to `>`, or `throw('Break')` into an active `try`/`catch` |
| `Break;` | HolyC helper: `throw('Break')` (same exception code) |

`TrapInit` enables 16550 RX IRQ + PLIC + `mie.MEIE`, so a normal `wfi` **does** wake on Ctrl-C. If you clear `mstatus.MIE` or `mie.MEIE` (or never call `TrapInit`), bare `wfi` will not see Ctrl-C until a timer or other IRQ wakes the CPU. Editors are not break-armed: `^C` is still a keystroke there.

`uart_hw_drain` clears `mstatus.MIE` for the LSR→RBR loop so a nested IRQ (UART or the break-poll timer) cannot empty the FIFO between the data-ready check and the read — otherwise QEMU’s 16550 returns the stale last `RBR` and the ring gets a duplicate key (`aa` per keystroke). Masking only `mie.MEIE` left the timer free to re-enter drain. Check: `make repl-uart-echo-pty`.

## Honesty

- Legacy `repl.elf` still uses **host slots** (`0x87001xxx`) for compile/run, Callers, MemMap, Regs, traps, etc. Inventory: [REGRESSION.md](../tests/REGRESSION.md).
- Graphics / WinMgr are **not** this UART REPL — use `make kernel-fb-smoke` / `kernel-win-smoke` ([BOARD_FB.md](../templeos-riscv/BOARD_FB.md)).
- Full DolDoc / mouse / net are not implemented.
